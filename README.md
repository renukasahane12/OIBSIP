# OASIS INFOBYTE – Data Analytics Internship

This repository contains the tasks completed during my **Data Analytics Internship at OASIS INFOBYTE**.

##  About the Internship

The internship focused on applying **Data Analytics, Machine Learning, and NLP techniques** to real-world datasets.

The tasks covered:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Customer Segmentation
* Natural Language Processing (NLP)
* Predictive Modeling
* Classification
* Model Evaluation
* Statistical Analysis

---

##  Tasks Completed

### Level 1

#### Task 1 – EDA: Retail Sales

* Exploratory Data Analysis
* Sales trend analysis
* Customer behavior analysis
* Statistical analysis and visualizations

#### Task 2 – Customer Segmentation

* Customer segmentation using K-Means clustering
* RFM-based customer analysis
* Cluster visualization
* Business insights

#### Task 3 – Data Cleaning

* Missing value treatment
* Duplicate removal
* Outlier detection
* Data type and format correction

#### Task 4 – Sentiment Analysis

* Text preprocessing
* TF-IDF feature extraction
* Machine learning-based sentiment classification
* Model evaluation

---

###  Level 2

#### Task 1 – House Price Prediction

* Exploratory Data Analysis
* Feature preprocessing
* Linear Regression
* Model evaluation

#### Task 2 – Wine Quality Prediction

* Data preprocessing
* Feature scaling
* Classification models
* Model comparison
* Feature importance analysis

#### Task 3 – Fraud Detection

* Class imbalance handling
* Logistic Regression
* Random Forest
* Fraud detection model evaluation

#### Task 4 – Google Play Store Analysis

* Data cleaning
* App category analysis
* Rating, reviews, and installs analysis
* Free vs. paid app analysis

#### Task 5 – Autocomplete & Autocorrect

* NLP preprocessing
* Word frequency analysis
* Bigram and trigram models
* Autocomplete system
* Edit-distance-based autocorrect

* **Programming Language:** Python
* **Data Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn
* **Natural Language Processing:** NLP, TF-IDF
* **Database:** SQL
