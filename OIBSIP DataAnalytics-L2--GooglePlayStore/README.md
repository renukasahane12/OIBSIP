# Google Play Store Analysis

## Dataset
https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Objective
Analyze Google Play Store data to understand app categories, ratings, reviews, installations, and other trends.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Work Performed
- Data cleaning
- Exploratory data analysis
- Category analysis
- Rating analysis
- Review and installation analysis
- Data visualization

## Files
- notebook/Google_Play_Store_Analysis.ipynb
- output/google_play_store_analysis.csv

## Conclusion
The analysis provided insights into app categories, ratings, reviews, installations, and other Play Store trends.
